# Ecoverse
EcoVerse: Digital waste management for Organic, Non-Organic &amp; Residual waste. Features 4-role RBAC (Admin, Koor, Worker, Visitor) with RW-specific data filtering, real-time analytics dashboards, and PDF/Excel reporting. Tech: React, Node.js, Express, MySQL/Sequelize, &amp; Argon2. Built for efficient community waste tracking.
